### About

I'm Tao. I'm nothing — just coding for hobby and for fun. I'm from Myanmar (Mon), now based in Kuala Lumpur, Malaysia. I build small tools, mostly around the Mon (mnw) language: keyboard drivers, name converters, and typing tutors. The Mon/mnw keyboard layout I built is now included as a default input method in Ubuntu and other Linux distributions. I also contribute Mon-language translations for Ubuntu on Launchpad.
